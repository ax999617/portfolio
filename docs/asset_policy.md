# Asset and Third-party Policy

## Repository license status

This repository does not currently declare a repository-wide license. Public visibility alone does not grant permission to copy, modify, or redistribute the code or archived assets. Historical model weights, ComfyUI workflows, model/LoRA/custom-node references, and candidate images also lack a complete public license chain.

## Portfolio rules

- Legacy `.pth` files remain labeled `legacy/unverified` and are not v2 experiment artifacts.
- ComfyUI archives remain outside the recommended path until content, metadata, dependency, attribution, and license review is complete.
- Frozen research PDFs/PNGs are shown only with their existing provenance; figures and CLD are not recalculated.
- Candidate outputs are never described as definitive workflow results without a verified input-to-output link.
- A future repository license must distinguish original code from third-party and historical assets whose rights may differ.

## Future publication checklist

1. Record the original path, source or author, and applicable license.
2. Inspect JSON and image metadata before publication.
3. Record model, LoRA, custom-node, and runtime versions.
4. Confirm whether redistribution, modification, and commercial display are permitted.
5. Withhold any asset whose status cannot be explained.
