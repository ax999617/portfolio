# Windows Automation Scripts — Legacy Appendix

> Supporting archive only. The discovered scripts use AutoHotkey v1-style syntax, while the supplied runtime context points to AutoHotkey v2. They are not presented as a currently supported utility.

## Preserved material

- `scripts/DesktopUIToggle.ahk`: original desktop UI toggle script.
- `scripts/DesktopUIToggle_Enhanced.ahk`: Windows 11-oriented variant.
- `scripts/*.bat`: historical setup, run, removal, and troubleshooting helpers.

The scripts record a small desktop automation experiment involving desktop icons and the taskbar. Review the source and use an isolated Windows account before any future compatibility work; the batch launchers are intentionally not presented as a default portfolio command.
